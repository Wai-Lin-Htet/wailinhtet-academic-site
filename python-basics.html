      2.1What is a variable?

      A variable stores a value (e.g., text, number, etc.). We can give a name to a variable. The value can be changed during the program.

      name = "Alice"
age = 20
print("Name:", name)
print("Age:", age)

      Output:

      Name: Alice
Age: 20

      The = sign assigns a value to a variable — it does not mean “equals”. Read name = "Alice" as “name gets the value Alice”.

      2.2Rules for variable names

      Letters, numbers, underscore
      Use letters, numbers and underscore (_). No other symbols.
      Start with a letter or underscore
      A name must start with a letter or underscore — never a number.
      No spaces
      my age is not allowed. Use my_age instead.
      Meaningful names
      Use meaningful names (e.g., name, age, total) so anyone reading your code knows what the variable holds.
      Common mistakes
      • Using a space in a name: first name = "Alice" is a syntax error.
      • Starting a name with a number: 1st_name is not allowed.
      • Using a meaningless name like x when age would be clear.

      Try it

      Python can perform calculations using operators. Common operators: addition, subtraction, multiplication, division, etc.

      OperatorMeaningExample
      +Add10 + 3 = 13
      -Subtract10 - 3 = 7
      *Multiply10 * 3 = 30
      /Divide10 / 3 = 3.33

      5.1Making decisions

      Conditionals are used to make decisions in a program. Python runs different code based on a condition (True or False).

      age = 18
if age >= 18:
    print("You are an adult.")
elif age >= 13:
    print("You are a teenager.")
else:
    print("You are a child.")

      Output:

      You are an adult.
      if
      Use if to check a condition.
      elif
      Use elif for another condition.
      else
      Use else for the default case.
      Comparison operators
      Conditions often use comparison operators (e.g., >=, <=, ==, !=).

      Indentation matters. The lines inside an if, elif or else must be indented by the same amount (4 spaces). Python checks the branches in order and runs the first one whose condition is True — then it skips the rest.

      OperatorMeaning
      ==Equal to
      !=Not equal to
      >Greater than
      <Less than
      >=Greater than or equal to
      <=Less than or equal to
      Common mistakes
      • Writing = (assign) instead of == (compare) inside a condition.
      • Forgetting the colon : at the end of the if line.
      • Forgetting to indent the lines inside the branch.

      6.1Repeating code

      A loop repeats a block of code multiple times. Python has two main types of loops:

      for loop
      Repeat for a set of items.
      while loop
      Repeat while a condition is True.

      6.2for loop

      fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

      Output:

      apple
banana
cherry

      The loop variable fruit takes each item from the list in turn. range(5) gives the numbers 0 to 4 — useful when you want to repeat a fixed number of times.

      6.3while loop

      count = 1
while count <= 5:
    print("Count:", count)
    count = count + 1

      Output:

      Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
      Common mistakes
      • Forgetting to change the condition inside a while loop — it runs forever (an infinite loop).
      • Using a while loop when a for loop is clearer (when you know how many times to repeat).

      Try it

      Use a for loop to print the numbers 1 to 5. Then do the same with a while loop.

      7.1What is a function?

      A function is a reusable block of code. It helps to organise code, avoid repetition and make programs easier to read.

      def greet(name):
    return f"Hello, {name}!"

message = greet("Python")
print(message)

      Output:

      Hello, Python!
      def
      Use def to define a function.
      return
      Use return to send a value back.
      Parameters
      A function can take parameters (e.g., name).

      A function does nothing until you call it. greet("Python") calls the function with the argument "Python", and return sends the result back to the caller. The value that comes back can be stored in a variable, like message above.

      Exam tip In the exam, a question may ask you to write a function that returns a value. Read the question carefully: if it says “return”, use return — do not print inside the function. The caller decides what to do with the returned value.

      8.1What is a list?

      A list is an ordered collection of items. It can store different types of data (e.g., numbers, text, etc.).

      numbers = [1, 2, 3, 4, 5]
numbers.append(6)
numbers.insert(0, 0)
numbers.remove(3)
numbers.pop()
print(numbers)

      Output:

      [0, 1, 2, 4, 5]

      Follow the steps: append(6) adds 6 at the end → [1, 2, 3, 4, 5, 6]; insert(0, 0) puts 0 at index 0 → [0, 1, 2, 3, 4, 5, 6]; remove(3) takes out the 3 → [0, 1, 2, 4, 5, 6]; pop() removes the last item (6) → [0, 1, 2, 4, 5].

      MethodWhat it does
      append(x)Add an item at the end
      insert(i, x)Insert an item at index i
      remove(x)Remove the first occurrence of x
      pop()Remove and return the last item
      clear()Remove all items

      The first item is at index 0: numbers[0] is 1 in the original list. len(numbers) gives the number of items.

      9.1What is a dictionary?

      A dictionary stores data as key-value pairs (e.g., name and age). Each key must be unique and cannot be changed (immutable).

      person = {"name": "Alice", "age": 20, "city": "New York"}
print(person["name"])
person["age"] = 21
person["email"] = "alice@example.com"
del person["city"]
print(person)

      Output:

      Alice
{'name': 'Alice', 'age': 21, 'email': 'alice@example.com'}
      Key-value pairs
      A dictionary uses key-value pairs.
      Unique keys
      Keys must be unique (e.g., “name”, “age”).
      Values can change
      The value can be changed (update).
      del
      Use del to remove a key-value pair.
      Exam tip Use square brackets with the key to read a value: person["name"]. If the key does not exist, Python raises a KeyError — check with in first (if "email" in person:) or use .get() (Day 60).

def deposit(amt): global balance; balance += amt; return balance
def withdraw(amt):
    global balance
    if amt > balance: return "Insufficient funds"
    balance -= amt; return balance

print("Remaining transaction ledger balance:", withdraw(250.0))
