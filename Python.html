5 For Loop 
for i in range(1, 6):
    print(i)

# Output: 1 2 3 4 5

# Loop through list:
for item in ["a", "b", "c"]:
    print(item)
6 While Loop 
i = 1
while i <= 5:
    print(i)
    i += 1

# Output: 1 2 3 4 5
7 Counting

Count how many times an item appears in a list:

lst = [1, 2, 2, 3, 2, 4]
count = lst.count(2)

print(count)  # Output: 3
8 Totaling (Sum)

Sum of numbers in a list:

nums = [10, 20, 30, 40]
total = sum(nums)

print(total)  # 100
9 Maximum

Find maximum value:

nums = [12, 5, 33, 7]
m = max(nums)

print(m)  # 33
10 Minimum

Find minimum value:

nums = [12, 5, 33, 7]
m = min(nums)

print(m)  # 5
11 List

13 2D Array (List of Lists)

Matrix / Table (Rows × Cols):

matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]

print(matrix[1][2])  # 6
14 Upper & Lower

String case conversion:

text = "Hello Python"

print(text.upper())  # HELLO PYTHON
print(text.lower())  # hello python
15 File Handling
Read a file: 
with open("data.txt", "r") as f:
    content = f.read()
    print(content)
Write / Append to a file: 
# Write (overwrite)
with open("out.txt", "w") as f:
    f.write("Hello Python!\n")

# Append
with open("out.txt", "a") as f:
    f.write("Append this line.")
