Types & Components of Computer Systems

Hardware, the CPU, signals, software types, memory, storage overview, OS interfaces, computer categories and emerging tech.

1.1 Hardware

Internal hardware lives inside the system unit:

CPUCentral Processing Unit — the primary processor that interprets and executes system instructions.
MotherboardThe main printed circuit board that connects every internal component so they can communicate.
RAMRandom Access Memory — volatile primary memory used for temporary data storage while processing.
HDD / SSDSecondary storage devices used for persistent, non-volatile data storage.
NICNetwork Interface Card — wired (Ethernet) or wireless (WNIC) hardware that connects a device to a network.
GPUGraphics Processing Unit — a specialised processor for rendering graphics, 3D images and video.

External hardware (peripherals): Input devices (mouse, keyboard, microphone, scanner, webcam) enter data; output devices (speaker, monitor, printer, projector, actuator) present processed data to the user.

1.2 CPU Components

  • ALU (Arithmetic Logic Unit) — performs arithmetic calculations (add, subtract) and logical decisions (AND, OR, comparisons).
  • CU (Control Unit) — coordinates and manages the flow of data and the execution of instructions across the processor and the system.

1.4 Software Types

Application software

Provides the services a user needs for a specific task: word processing, spreadsheets, database management (DBMS), control & measurement software, apps/applets, video editing, graphics editing (bitmap vs vector), audio editing, and CAD (Computer-Aided Design) for precise 2D/3D models and cost estimation.

System software

Manages the hardware and provides the platform application software runs on:

CompilerTranslates high-level code into machine code all at once, producing an independent executable file.
LinkerLinks separate object code files and compiled libraries into one executable program.
Device driverLets the OS communicate with and control a specific hardware device, e.g. a printer or graphics card.
Operating SystemManages hardware resources (RAM, CPU cycles) and provides a user interface, e.g. Windows, macOS, iOS.
UtilitiesSupport software that maintains, optimises and protects the system — antivirus, disk defragmenters, backup tools.

1.5 Primary Memory

  • RAM — temporary, volatile memory (loses data when powered off); holds the running apps, OS components and data in active use.
  • ROM — permanent, non-volatile memory (keeps data with no power); stores the BIOS and the bootstrap loader (start-up instructions).

1.6 Storage Technologies Overview

  • Magnetic — magnetised platters or tape (HDD, magnetic tape).
  • Solid state — flash memory chips (NAND), no moving parts (SSD, USB, SD cards).
  • Optical — a laser reads/writes pits and lands on a reflective disc (CD, DVD, Blu-ray).
  • Cloud — files stored on remote internet servers across public, private or hybrid environments.

1.8 Computer Categories & Processing

Categories: Desktop/All-in-One, Mobile computers (laptop, tablet, smartphone, smartwatch), Embedded computer (built into appliances like a washing machine), Server, Mainframe (bulk financial transactions), Supercomputer (scientific calculations), Minicomputer, Microcomputer, AI computers, and Quantum computers.

Binary vs Quantum: traditional microcomputers process bits as either 0 or 1. Quantum computers use qubits, which use superposition to exist as 0, 1, or both at once — enabling far more complex calculations.

1.9 Emerging Technologies

  • Artificial Intelligence (AI) — systems that simulate human intelligence: natural language processing (translation, voice assistants), smartphone facial recognition and predictive text, and autonomous vehicles that navigate and react in real time.
  • Immersive tech — Augmented Reality (AR) overlays digital content on the real world (e.g. navigation heads-up display); Virtual Reality (VR) fully immerses the user in a generated 3D world using a headset; Mixed Reality (MR) blends real and virtual objects that interact in real time.

Exam tip

If asked to "describe" a difference (e.g. RAM vs ROM, or CLI vs GUI), always give a point for each side — one mark for RAM being volatile/temporary, another for ROM being non-volatile/permanent. Don't just name them.

1.1 Hardware and software

Hardware = the physical components of a computer system. External: keyboard, mouse, monitor, printer, camera. Internal: motherboard, CPU, RAM, ROM, graphics card, sound card, NIC, HDD/SSD.

Internal component Key exam points
Motherboard Printed circuit board; lets the processor and other hardware communicate; acts as a hub with sockets and slots
CPU / processor Executes program instructions. ALU = arithmetic and logic operations; CU = fetches, decodes and executes instructions; also holds registers
RAM Temporary storage for data/programs/part of OS in use; read and write; volatile

Sound card Produces sound through speakers; records sound from a microphone
NIC Connects a device to a network (wired or wireless); has a unique MAC address
HDD / SSD Permanent internal storage for files, OS and applications. HDD = magnetic; SSD = solid-state

Software = programs that control the computer and process data.

Applications software (does user tasks) System software (runs the hardware / platform for other software)
Word processing, spreadsheet, database, CAD, video/audio/graphics editing, control and measurement software, apps and applets Operating system, compiler, linker, device drivers, utilities (antivirus, backup, disk repair, defragmenter, file management)
  • Compiler: translates a whole high-level language program (source code) into machine code (object code); compiled code can be re-run without recompiling.
  • Linker: combines object files/modules from a compiler into one runnable program.
  • Device driver: lets the OS communicate with a hardware device (e.g. printer); without it the device will not work.
  • Database: table = rows (records) and columns (fields). Spreadsheet: cells identified by column letter and row number (e.g. B6).
  • App: does a fairly substantial task (banking, streaming). Applet: small program for a single task, usually embedded in a web page and run in the browser.
  • Analogue data changes smoothly (infinite values); digital data is discrete binary (0/1). Analogue to computer needs an ADC; computer to a device (motor, speaker) needs a DAC.

Past Paper Exam Practice — 10 Topical Questions

Q1: Internal Components & Roles
Explain the primary functional difference between the Arithmetic Logic Unit (ALU) and the Control Unit (CU) within the central processing unit. [2]
View Markscheme Points
  • ALU: Executes all mathematical calculations (addition, subtraction) and logical decisions / comparisons (AND, OR, NOT).
  • CU: Directs and coordinates data flow and operations across the CPU; fetches, decodes, and manages the execution of instructions.
Q2: Primary Storage Characteristics
Describe two key differences between Random Access Memory (RAM) and Read Only Memory (ROM). [4]
View Markscheme Points
  • RAM is volatile memory / loses contents when power is turned off; ROM is non-volatile / retains contents permanently without power.
  • RAM is read and write memory / allows modifications; ROM is read-only memory / cannot be altered by normal user operations.
  • RAM holds currently executing programs, active data, and loaded OS parts; ROM stores bootstrap instructions / BIOS / start-up routines.
Q3: Analogue to Digital Conversion
State why an Analogue-to-Digital Converter (ADC) is required when sensors collect data for a microprocessor. [2]
View Markscheme Points
  • Sensors capture continuous, analogue physical measurements from the environment.
  • Microprocessors/computers only process discrete, digital electrical signals (binary 0s and 1s).
  • The ADC translates physical analogue data into binary values the CPU can interpret.
Q4: Operating System Interfaces
Discuss the advantages and disadvantages of using a Command Line Interface (CLI) compared to a Graphical User Interface (GUI). [4]
View Markscheme Points
  • CLI Advantage: Requires far less RAM and processing power; allows rapid, direct command execution by experienced users; commands can be scripted.
  • CLI Disadvantage: Complex commands and strict syntax must be memorised; intolerant of typing errors.
  • GUI Advantage: Intuitive and user-friendly WIMP layout; visual icons require no prior technical command memorisation.
  • GUI Disadvantage: Uses significantly more memory and system resources; limited strictly to on-screen pre-set actions.
Q5: Embedded Computers
Identify what is meant by an embedded computer and give two everyday household appliances that contain one. [3]
View Markscheme Points
  • Definition: A dedicated microprocessor system built permanently into a larger mechanical/electronic device to perform a specific dedicated control task.
  • Examples (any two): Washing machine, microwave oven, dishwasher, modern car engine management, smart thermostat.
Q6: System Software Utilities
Identify two utility programs and describe the primary function of each. [4]
View Markscheme Points
  • Disk Defragmenter: Reorganises fragmented file clusters contiguously across magnetic storage blocks to improve read/write access speeds.
  • Antivirus software: Scans, quarantines, and cleans/deletes malicious files using updated signature databases.
  • Backup software: Creates duplicated archive copies of files to external or cloud drives for disaster recovery.
Q7: Compilers vs Interpreters
Describe two functional differences between a compiler and an interpreter. [2]
View Markscheme Points
  • A compiler translates the entire high-level source code into a standalone machine-code executable file at once; an interpreter translates and executes source code line-by-line.
  • Compiled programs run faster once built and do not require original source code; interpreted programs halt immediately when an error is encountered, facilitating rapid debugging.
Q8: Mainframes vs Microcomputers
State two reasons why major financial institutions use mainframe computers instead of standard desktop microcomputers. [2]
View Markscheme Points
  • Mainframes can process massive volumes of concurrent input/output transactions in real time (high throughput).
  • Mainframes provide fault-tolerant redundant hardware ensuring zero-downtime 24/7 reliability.
Q9: Virtual Reality (VR) Hardware
Identify two specialised hardware devices used when interacting with a Virtual Reality system. [2]
View Markscheme Points
  • Head-Mounted Display (HMD) / VR Headset with dual micro-displays and motion tracking sensors.
  • Haptic feedback data gloves / sensor-equipped hand controllers.
Q10: Quantum Computing Principles
Explain how quantum computing bits (qubits) differ fundamentally from traditional binary bits. [2]
View Markscheme Points
  • Traditional bits can only represent one state at a time (either a 0 or a 1).
  • Qubits exploit the quantum phenomenon of superposition, existing as 0, 1, or both simultaneously, enabling parallel computing of massive mathematical datasets.

Input & Output Devices

Manual input, sensors, direct data entry, cards, barcodes/QR codes, and every output device you need for the exam.

2.1 Manual Input Devices & Sensors

  • Keyboard — fast for skilled typists but slower than direct data entry and prone to typing errors.
  • Numeric keypad — used at ATMs and POS terminals for fast numeric/PIN entry.
  • Pointing devices — mouse, touchpad, tracker ball, joystick, driving wheel; control the on-screen cursor.
  • Scanner — converts paper documents into digital form, often using OCR (Optical Character Recognition) to turn a scanned image of text into editable text.
  • Digital camera and microphone — capture images and analogue sound respectively.

Key term, in full

Sensor — a device that measures a physical property (temperature, pressure, light, sound, moisture, pH) in the real world. The processing loop is: Sensor (analogue) → ADC → microprocessor compares the reading with preset parameters → DAC → actuator/motor/alarm reacts.

2.2 Direct Data Entry, Cards & Barcodes

OMROptical Mark Recognition — reads pre-printed marks in fixed positions, e.g. multiple-choice exam sheets or lottery tickets.
OCROptical Character Recognition — scans printed or handwritten text and converts it into editable digital text.
MICRMagnetic Ink Character Recognition — reads the special magnetic ink characters at the bottom of bank cheques for automated processing.
RFID / NFCRadio Frequency Identification / Near Field Communication — contactless tracking and payment technology.
Barcode (1D) vs QR Code (2D)
FeatureBarcode (1D)QR Code (2D)

Scanning methodLaser scanner, needs direct alignmentSmartphone camera or scanner, any angle

2.3 Output Devices, Displays, Printers & Projectors

Displays: CRT (heavy, legacy, hot); LCD (flat panel, CCFL backlight); LED (LCD backlit by LEDs — brighter, thinner, more efficient); OLED (self-emissive pixels, true blacks, flexible); IPS (wide viewing angles, accurate colour).

Printers: Laser (fast, dry toner, crisp text for offices); Inkjet (liquid ink droplets, great for photos, cheaper but slower and can smudge when wet); 3D printer (builds solid objects layer-by-layer from a CAD model); Dot-matrix (impact printer, noisy, used for continuous or multi-part carbon-copy paper).

3D printing in medicine

3D printing starts with a CAD model. Applications include custom prosthetic limbs (faster and cheaper than traditional manufacturing), bioprinted tissue to repair damaged organs and reduce transplant waiting lists, and biodegradable artificial blood vessels used in surgery.

Projectors: DLP uses tiny micro-mirrors for high contrast and portability; LCD projectors use three glass panels (red, green, blue) for bright, colour-accurate images.

2.1 Input devices and their uses

Keyboard: pressing a key makes contact between conductive layers; the CPU uses an index file to identify the character. Uses: entering text/numbers/commands. Advantages: fast text entry, well known, easy verification against the source document. Disadvantages: hard for people with limited wrist/arm movement, slower than direct data entry, uses desk space.

Numeric keypad: numbers only. Uses: ATMs (PIN), mobile phones, POS terminals (manual barcode entry), chip and PIN devices, spreadsheets. Adv: fast numeric entry; small/portable. Disadv: small keys; number order may not be intuitive.

Multimedia projector: projects computer/TV/DVD output onto a large screen. Uses: training, advertising, home cinema. Adv: many people can see the presentation; avoids crowding round or networking many computers. Disadv: fuzzy images, expensive, awkward set-up.

Speakers: digital data → DAC (analogue current) → amplifier → loudspeaker (current in coil on iron core reacts with a permanent magnet, moving a cone to make sound). Storage Devices & Media

Magnetic, solid-state and optical backing storage, plus cloud storage vs cloud computing.

3.1 Magnetic Backing Storage

HDD (Hard Disk Drive) — spinning magnetised platters, a read-write head and an actuator arm. Speed is measured in RPM; rotational latency is the delay while the correct sector rotates under the head. Advantage: large capacity at low cost per GB. Disadvantage: moving parts are easily damaged by shocks or drops.

Other magnetic media: portable HDD (USB, for large backups), magnetic tape (low-cost, high-capacity, sequential-access — good for long-term archiving), and the legacy floppy disk.

3.2 Solid-State Backing Storage

Uses non-volatile NAND flash memory chips with zero moving parts: SSD (fast, durable), USB flash drive (portable, plug-and-play), and SD/XD/CFast memory cards used in cameras, phones and tablets.

3.3 Optical Backing Storage

A laser burns and reads microscopic pits and lands on a spiral track on a reflective disc.

  • CD — about 700 MB.
  • DVD — about 4.7 GB, red laser; dual-layer DVDs have two reflective layers.
  • Blu-ray — 25–50 GB, short-wavelength blue laser (405 nm) for tighter pit packing.

Disc formats: -R (recordable once), -RW (rewritable), -ROM (read-only), DVD-RAM (simultaneous read/write, sector-based).

3.4 Cloud Storage vs Cloud Computing

Don't mix these up

Cloud storage is like a virtual remote hard drive — a place where your files simply sit. Cloud computing is like a virtual computer (CPU + RAM + programs) that actively runs processing tasks and applications over the internet, without using your local hardware.

  • Public cloud — infrastructure owned by a third-party provider, open to public clients.
  • Private cloud — dedicated infrastructure behind one company's own firewall.
  • Hybrid cloud — combines public and private to balance security and cost.

3.3 Solid-state media and devices

  • No moving parts; not magnetic. Data stored as 0/1 in transistors in NAND flash chips using floating gate and control gate transistors (charged floating gate = 1, uncharged = 0).   • SSD (solid-state drive): replacing HDDs as main backing storage.
    • Benefits: more reliable (no moving parts); lighter; no need to "spin up"; lower power use; run cooler; very thin; access time about 0.1 ms vs 10 ms for HDD; faster data transfer.
    • Drawback: limited endurance (a finite number of write operations), so not yet used everywhere in servers; more expensive per GB and lower capacity than HDD.
  • Pen drive (memory stick) / USB flash drive: flash memory with a USB connector, powered from the computer. Uses: transporting files between computers, small backups, dongle (software anti-piracy). Adv: compact and portable; needs no extra software; not affected by magnetic fields. Disadv: cannot be write-protected; easy to lose; corrupts if removed during read/write. (Every pen drive is a flash drive, but not every flash drive is a pen drive.)
  • Memory cards (SD, XD, CFast; micro SD): Uses: cameras, phones, MP3 players, hand-held devices. Adv: very compact, removable, no moving parts, large capacity. Disadv: more expensive per GB than HDD; lower capacity; finite number of read/write cycles; easy to lose; may need a card reader.

3.4 The future of storage

CDs and DVDs are becoming obsolete: many computers have no optical drive. Flash memory is the main way to transfer files, and music/movies are increasingly stored on HDD/phones, in the cloud, or streamed over the internet (smart TVs stream without DVD/Blu-ray players).

4.1 Core Concepts

Network — two or more devices connected to share data, resources and communication. Internet — a global WAN connecting millions of devices. World Wide Web — the collection of multimedia web pages hosted on web servers, following W3C standards.

4.2 Network Hardware — learn what each device does

4.3 Network Addressing

IP address — the logical location of a device on a network. IPv4 uses 32 bits, written in denary (e.g. 192.168.1.1). IPv6 uses 128 bits, written in hexadecimal, to solve the shortage of IPv4 addresses.

MAC address — uniquely identifies hardware, set at the factory. Built from 48 bits (6 hex pairs): the first 24 bits are the manufacturer ID, the last 24 bits are the device's serial number.

4.4 Types of Networks

  • WAN — covers a large area (cities, countries); fibre-optic, leased lines, satellites.
  • WLAN — a wireless LAN, usually Wi-Fi over 2.4 GHz / 5.0 GHz radio waves.
  • LAN — a small area (home, school, office), using switches or hubs.
  • PAN — a very small personal range (~10 m), commonly Bluetooth.

4.5 Security & Access Control

Biometrics (fingerprint, face, iris), physical tokens (smart cards, security keys, USB dongles), electronic tokens / OTP (one-time passcode via SMS, email or an app), and strong passwords (mixing upper/lowercase, numbers and symbols).

4.6 Anti-Malware Software

Anti-virus — scans files against malware signature databases, quarantines suspicious files, and cleans infections. Firewall — hardware or software that monitors incoming/outgoing traffic against security rules.

4.7 Electronic Conferencing

Hardware needed: microphone (audio in), webcam (video in), speakers/headphones (audio out). Common platforms: Zoom, Google Meet, Microsoft Teams.

Common mix-up

A hub broadcasts to everyone (dumb device); a switch sends only to the right device (smart device). A router connects different networks together and routes by IP address; a bridge connects two parts of the same network and filters by MAC address.

4.1 Networks

A network = two or more computers/devices connected to share resources (printers, software, data). The internet is the largest (global) network; access is provided by an ISP (internet service provider).

4.1.1 Common network devices and terms

  • NIC (network interface card): lets a device connect to a network; turns binary data into an electrical signal; usually integrated in the motherboard. WNIC = wireless version, uses an antenna (microwaves).
  • MAC address (media access control): hard-coded at manufacture, uniquely identifies a device on a network. 48 bits, six pairs of hex digits (NN-NN-NN-DD-DD-DD: first half = manufacturer code, second half = device serial number). Never changes (changes only if the NIC is replaced); a "physical address"; useful for identifying network faults.
  • IP address (internet protocol): identifies the location of a device on a network; given by the ISP; changes when you connect from a different place. IPv4 = 32 bits, four denary groups (e.g. 192.168.1.1). IPv6 = 128 bits, eight groups of hex separated by colons (created because IPv4 addresses are running out).
  • Data packets: data is split into packets, each sent separately. A packet header contains: sender's IP address, receiver's IP address, packet sequence number (to reassemble in order), packet size (to check it arrived intact), and how many packets make up the message. Packets pass through several routers ("hops") to the destination.
Device What it does

6.1 Communication applications

  • Newsletters and posters (made with word processing). Disadvantages: can be hacked/pharmed; users need a computer and internet; must be maintained and promoted; hard to target the correct audience; expensive to build and secure.
  • Multimedia presentations (with a projector): Advantages: animation, sound and video grab attention; hyperlinks to websites/cloud files; transition effects; flexible/tailored to audience. Disadvantages: expensive equipment; equipment can fail; may need internet; focus on the medium rather than the message; easy to overdo effects.

Needs stable fast internet (about 25 Mbit/s for HD). Data packets are buffered so playback is smooth; a larger buffer reduces freezing.

6.2 Modelling applications (simulations)

A simulation = a computer model of a real system (based on mathematical representations) used to study, predict and influence behaviour.

  • Advantages: cheaper than building the real thing; safer; try many scenarios; can test what is impossible in real life (space, nuclear reactors, crash tests); faster than real time (climate change, population growth).
  • Disadvantages: only as good as the program and data; modelling can be costly; people may not trust results (models differ from reality).
  • Examples: personal finance (spreadsheet "what-if" models, e.g. a tuck shop’s profit); bridge and building design (loading from traffic, wind, earthquakes, tidal waves/ice, vibration; fire; movement of people in lifts; combined with scale-model wind-tunnel tests); flood water management (river/inlet cross-sections, bridges/weirs/sluices, tides/wind, boundary conditions, dates, calibration data from past floods; Venice used sensors for faster, safer, continuous, more accurate warnings); traffic management (motorway lane closures: compare models A and B at different densities/speed limits/breakdowns; traffic-light simulation at a Y-junction using induction loop sensors to count vehicles, recording time of day, weekends/holidays, clearance time, pedestrians, turns; validate the model against real data, then test light timings); weather forecasting (weather stations with sensors e.g. air pressure, temperature, wind, rainfall feed a very powerful computer model; results compared with actual weather so the model "learns").

6.3 Computer-controlled systems

  • Robots in manufacturing use sensors and actuators; good at repetitive tasks. 6.5 Booking systems

Used for flights, hotels, theatres/concerts, sports events, trains.

  • Advantages: prevents double-booking; instant availability feedback; book any time; easy seating-plan browsing; seats can be held temporarily; e-tickets save postage; special offers via email; apps. Disadvantages: expensive to set up/maintain; customers need a device and internet; harder to cancel/refund; system/server downtime stops bookings; poorly designed sites cause mistakes; no personal relationship.

6.6 Banking systems

  • ATM: insert card + PIN → choose service (withdraw, balance, deposit cheque via OCR, statement). Advantages: cash any time; many services without a branch; access from anywhere; quicker than queuing. Disadvantages: theft risk at night; shoulder surfing and card cloning; charges/limits; faulty card = no transaction; loss of personal contact.
  • EFT (electronic funds transfer): direct bank-to-bank transfer (e.g. salaries, bill payments). Secure, quick, cheaper than cheques; can dispute for a period; but funds must be available immediately, cannot be easily reversed, cannot guarantee recipient identity.
  • Chip and PIN payment process: PIN keyed in → card checked (expiry, stolen) → PIN read from chip and compared → if match continue → retailer's bank contacts customer's bank → funds/validity checked → authorisation code sent → amount deducted from customer's account and credited to retailer's → receipt printed.
  • Credit vs debit cards: credit = borrow (interest-free period, customer protection, but high interest, credit damage, spending temptation); debit = money comes straight from your account (no credit/debt, but less protection and security risks).
  • Cheques: safer than cash, can be stopped/traced, but slow, expensive, and easier for fraud. Image-based clearing: OCR reads cheque details, an image and digital record are sent to a central facility, which sends "request to pay" to the payer's bank → pay/no-pay usually under 24 hours.
  • Internet (online) banking and shopping: Advantages: no travel, 24/7, worldwide market and cheaper prices, no queues, banks/shops save staff costs. Disadvantages: isolation, security (hacking, phishing, fraudulent sites), need computer/internet, can't see goods physically, delivery traffic/pollution, closure of high-street shops/banks, errors when transferring money. Effects on companies: lower staff costs, bigger customer base, extra cost of website security/delivery, less customer–employee interaction, fewer robberies.

6.7 Computers in medicine

  • Information systems: patient records, pharmacy records (check drug interactions), databases used to help diagnosis; patient records contain unique ID, medical history, X-rays/CT scans.
  • 3D printers: print anatomical models for surgeons (planning from CT and MRI scans), prosthetics, artificial tissue using bio-inks (biomimetic), and 3D printed medicines tailored to the individual (patient-centric medicine): better release control, cost saving, better targeting, less risk of overdose.
  • Expert systems (see 6.8) are also used for diagnosis.

6.8 Expert systems

Imitate an expert's knowledge to solve problems: medical diagnosis, prospecting for oil/minerals, fault diagnostics (car engine, circuit board), strategy games (chess), tax and financial planning, route scheduling, identification of plants/animals/chemicals.

Component Role
User interface Dialogue with the user (often yes/no questions, boxes, prompts)
Knowledge base Database of facts: objects and their attributes, gathered from human experts
Rules base Set of inference rules (IF...THEN logic)
Inference engine Problem-solving part; searches the knowledge base using the rules base; asks the user questions and draws conclusions
Explanation system Explains the reasoning behind conclusions (and suggested actions, with probabilities)

Building one: gather expert information → populate the knowledge base → create rules base → set up inference engine → develop user interface → test thoroughly. Example: identify an animal by questions (does it make sonic sounds? skin-covered body?) → conclusion: whale. 6.9 Computers in the retail industry

  • Barcodes: parts: manufacturer's code, product code, check digit (error detection). Automatic stock control at POS: items scanned → barcode matched in the stock file → price returned to POS → stock level reduced by one → if stock ≤ re-order level, an order is placed automatically and the item is flagged as "ordered" → when goods arrive, cartons' barcodes update stock → itemised bill produced → daily takings file updated → loyalty points updated.
  • EFTPOS: payment at POS using chip and PIN, magnetic stripe, or contactless/NFC. Chip and PIN advantages: more secure than magnetic stripe; quicker (also allows contactless). Disadvantages: PIN fraud/observation; not accepted everywhere.
  • NFC/mobile wallets: phone held near terminal; NFC communication is encrypted and dynamic (changes every time); tokenisation (a substitute token, not the real card number, is stored/sent); protected by touch ID/face ID.

6.10 Recognition systems

  • OMR (school registers, exams, surveys, lottery): fast and accurate but forms must be carefully designed, only works with pen/pencil marks, limited to preset options.
  • ANPR (automatic number plate recognition): camera images processed with OCR. Uses: car park entry/exit and fees, average-speed cameras, congestion charging, security. Advantages: no guards needed, faster than tickets, monitors behaviour. Disadvantages: privacy issues, damaged/dirty plates not read, number plate cloning, less manned surveillance.
  • RFID: tag (microchip + antenna), passive (powered by reader, most common) or active (battery). Uses: livestock tracking, retail/warehouse tracking, passports, car park access, toll roads/weigh stations, car production lines, contactless cards. Advantages: no line of sight, robust, harder to forge than barcodes, fast, read/write, bulk reading. Disadvantages: tag collision, jamming, hacking, initial cost.
  • NFC (subset of RFID, very short range): peer-to-peer mode (two devices exchange data), read/write mode (active device reads a passive tag, e.g. advertising posters), card emulation (phone works as a contactless card for payments/transport).
  • Biometrics: face, fingerprint/thumb, iris and retina recognition, voice. Retina: unique blood-vessel pattern at the back of the eye; infrared photo; very secure but invasive, slow, only in high-security settings. Iris: coloured part around the pupil; camera using visible and near-infrared light; used in immigration control, banks.

6.11 Satellite systems

  • GPS (global positioning system; a GNSS run by the USA) uses satellites with atomic clocks to determine exact location; satnav uses it for route guidance. Advantages: safer than paper maps; warns of one-way streets/closures; estimates arrival time; fastest route/avoid towns; shows petrol stations. Disadvantages: out-of-date maps; road closures not always known; loss of signal; wrong start/end point gives wrong route.
  • GIS (geographic information system): captures, stores, analyses and displays spatial (location-based) data as layered maps (e.g. planning, utilities, emergency services).
  • Media communication: satellite TV and satellite phones (broadcast/communication over long distances and remote areas).

Type What it does

    • Online card use: security code (CVV), SSL, two-factor authentication.

    • Fingerprint: compares ridge/valley patterns; unique, cannot be lost or shared; but relatively expensive, damaged fingers cause problems, civil-liberty concerns, dirty/wet skin errors.

9.1 Audience appreciation

When planning any ICT solution (presentation, website, game, database, VR system) consider the audience: knowing their characteristics and needs makes the solution fit for purpose and more successful.

10.1 Communication with other ICT users using email

Email = electronic messages sent over a network. Features: To, Cc, Bcc, subject, body, attachments, reply, forward, email groups.

  • Laws and codes of practice: many countries have laws against misuse of email; organisations set an acceptable use policy/code of practice. Companies may limit which devices/accounts staff use and what can be sent. Emails are subject to copyright law.
    • Unacceptable content: abusive, profane, inflammatory, coercive, racist, exploitative or violent messages; illegal material; confidential information you’re not entitled to share (read only if you are the intended recipient).
    • Security of email: strong passwords (not a pet’s name), change regularly, spam filters (send suspicious mail to a junk folder), anti-virus and anti-spam software. Emails can suffer passive attacks (interception/reading) and active attacks (viruses, phishing).
    • Netiquette (internet etiquette): be polite and respectful; avoid capitals ("shouting"); be clear and concise, check spelling; don't post inappropriate content; remember posts are usually public; respect others’ privacy/copyright; don't spam or forward unnecessary mail.
  • Email groups: one name refers to many addresses. Uses: send one email to many people easily; organisations group people for targeted marketing; set up meetings/video conferences; spammers buy addresses to create groups. Group addresses should be typed individually/checked so all correct recipients are included.
  • Cc and Bcc: To = main recipients; Cc (carbon copy) = interested parties, visible to all recipients; Bcc (blind carbon copy) = hidden from all other recipients. For a group email, put your own address in To and the named group in Bcc, so recipients cannot see (and harvest) others’ addresses.
  • Sending attachments: limits on file size/type (e.g. executable files such as .exe, .msi, .bat, .cmd are often blocked); options: compress files (zip), or upload to a web/file-transfer service and share a link. Too many or very large emails can get a sender blacklisted by the ISP.
  • Spam (junk email): sent in bulk, unsolicited (also spambots in videos/comments). Effects: uses people’s time; annoying; uses up internet bandwidth (slows it down); can contain viruses or phishing scams; clogs inboxes.

    1. Author/source: can you verify who wrote it; is it reliable?
    2. Accuracy: can facts be verified elsewhere; is it free of spelling/grammar errors?
