Von Neumann architecture and the fetch-decode-execute cycle

Program instructions and data share one memory. Step through a small program (LOAD, ADD, STORE) and watch the registers, the three buses and the memory change.

Cycle log

Registers: PC holds the address of the next instruction; MAR holds the address being read or written; MDR holds the data just read or about to be written; CIR holds the instruction being decoded; ACC holds the result of ALU work. CU decodes instructions and sends control signals; ALU does arithmetic and logic.

CISC and RISC processors

Compare the two designs, then watch RISC-style pipelining overlap the five stages of each instruction.

Pipelining simulator

Stages: IF (instruction fetch), ID (decode), OF (operand fetch), IE (execute), WB (write-back). Each stage takes one clock cycle.

Karnaugh maps

Click an output (X) in the truth table or a cell in the K-map to flip it. The simplest sum-of-products expression is found for you. The K-map columns use Gray code (00, 01, 11, 10) so neighbours differ by one bit.

SR flip-flop (NOR gates)

Two cross-coupled NOR gates store one bit. Toggle S (set) and R (reset) and watch Q and its inverse change. Try S = 1, then S = 0 to see the memory.

Shortest path: A* and Dijkstra

Step through each algorithm on the textbook graph. Dijkstra expands the node with the smallest g (cost so far). A* expands the smallest f = g + h, where h is the heuristic estimate to the goal.
