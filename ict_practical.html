Sections 11–16 are foundation skills

File management, images, layout, styles, proofing, and graphs and charts are not examined on their own. They are the skills you use inside Papers 2 and 3 — for example, you place and resize an image (Section 12) inside a document (Section 17), and you build a chart (Section 16) inside a spreadsheet (Section 20) or a presentation (Section 19).

Evidence rules — read this before every practical exam

  • No internet and no email during both practical papers.
  • Electronic source files are provided for each task. They must be loaded onto your computer before the exam starts.
  • Work through the steps of each task in order.
  • Produce evidence of your work by taking screenshots and placing them in an Evidence Document, and by making printouts.
  • Enter your centre number, candidate number and name electronically on every piece of evidence before it is sent to the printer.
  • Website authoring uses HTML and CSS only — no scripting language is required.
11

File management

Before you can do any practical work, you must find files, save them in the right place with the right name, and export them in the format the task asks for.

What you must be able to do

  • Locate stored files, and open and import files of different types.
  • Save files in a planned hierarchical folder structure (folders inside folders).
  • Save files using appropriate file names — exactly as the task tells you.
  • Save and print files in many formats: a document, screenshots, database reports, data tables, graphs/charts, a web page in browser view, and a web page in HTML view.
  • Save and export in an application file format: .docx, .doc, .xlsx, .xls, .accdb, .odb, .rtf, .pptx, .ppt.
  • Save and export in a generic file format: .csv, .txt, .rtf, .pdf, .css, .htm, .jpg, .png.
  • Compress files (.zip, .rar) to reduce file size for storage or transmission.

Know and understand: the characteristics and uses of file formats (.css, .csv, .gif, .htm, .jpg, .pdf, .png, .rtf, .txt, .zip, .rar) — and why generic formats are needed. A generic format can be opened on any computer, in any software; an application format usually needs that exact program.

Worked example — set up your exam folders and save in the right format

  1. Create a folder called 0417_Paper2. Inside it, create three sub-folders: Source, Work and Evidence.
  2. Copy the source files the exam gives you into Source. Never change the source files — work on a copy in Work.
  3. Open the copy and save your work with the exact file name the task asks for, for example Task1_Letter.docx in the Work folder.
  4. When the task asks for a PDF, use File → Save As → PDF (do not just change the file name — the file type must really change).
  5. When the task asks for a smaller file, compress it: right-click the folder → Send to → Compressed (zipped) folder, or use 7-Zip → Add to archive → .zip.
  6. Before printing, check the file name, the folder, and the file extension one more time.

Exam tips

Never overwrite the original source files — if you make a mistake you need the original to start again. A file name that does not match the task can lose the mark, even if the work is correct. A .csv file saves data only — all formatting is lost, so never save your finished spreadsheet as .csv unless the task tells you to. Always check the file extension before saving: .docx is not the same as .pdf.

12

Images

You will place images into documents, presentations and web pages — in exactly the size and position the task asks for.

What you must be able to do

  • Place an image with precision.
  • Resize an image as specified, and maintain or adjust the aspect ratio.
  • Crop an image (cut off part of it).
  • Rotate an image.
  • Reflect (flip) an image horizontally or vertically.
  • Adjust the brightness and the contrast of an image.
  • Group and layer images: group and ungroup, move to the front or to the back.

Know and understand: reducing the file size of an image can be done by reducing the resolution or the colour depth.

Worked example — place the school logo in a document header

  1. Insert the image: Insert → Pictures → This Device, then select logo.png.
  2. Move it into position: drag it to the top-right corner, or use Picture Format → Position to set the exact position.
  3. Resize it exactly: Picture Format → Size → set the width to 4 cm. Keep Lock aspect ratio ticked, so the height changes with the width.
  4. Crop it: Picture Format → Crop → drag the top edge down by 1 cm to remove the empty space above the logo.
  5. Fix the brightness: Picture Format → Corrections → set Brightness to +10% and Contrast to +10%.
  6. Layer it correctly: right-click the logo → Bring to Front, so it sits above the banner shape behind it.
  7. Group it with the banner: select both objects (hold Ctrl and click each one) → right-click → Group. Now they move as one object.

Exam tips

Resizing without locking the aspect ratio stretches the image — examiners check this. Cropping removes part of an image; resizing makes the whole image smaller — they are not the same thing. Flip is not the same as rotate: flipping mirrors the image. After grouping, the images move as one — ungroup them if you need to edit one part alone. Reducing resolution makes the file smaller but also makes the image less sharp — only reduce it as far as the task asks.

13

Layout

Layout is how a document is built: the text, the objects in it, the tables, and the headers and footers. In this section "document" means any file you work on in Sections 16 to 21.

What you must be able to do

  • Create a new document or edit an existing one. Enter and modify text and numbers with total accuracy.
  • Edit text and numbers: highlight, delete, move, cut, copy, paste, drag and drop.
  • Place objects into the document from many sources: text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract.
  • Wrap text around a table, chart or image: above, below, square or tight.
  • Work with tables: create a table with a specified number of rows and columns; place text or objects in a table; edit a table (insert or delete rows and columns, merge cells); format a table — horizontal alignment (left, right, centre, fully justified), vertical alignment (top, middle, bottom), show or hide gridlines, wrap text inside a cell, shade or colour cells, adjust row height and column width.
  • Use headers and footers: create or edit them; align their contents consistently (left margin, right margin, centred within margins); place text and automated objects in them — file information, page numbering, total number of pages, date, time.

Know and understand: the purpose of headers and footers — information that repeats on every page, such as the document title, the page number, or the date.

Worked example — build a price table with a header and footer

  1. Create the table: Insert → Table → 3 columns × 4 rows.
  2. Type the headings in the first row: Item, Price, Stock. Then type the data in the rows below.
  3. Merge the title row: select the first row → Table Layout → Merge Cells → type Price List — 2027 and centre it.
  4. Format the table: select the heading row → Table Design → Shading → light grey. Set the heading cells to horizontal alignment centre and vertical alignment middle.
  5. Adjust the size: drag the column borders until every word is fully visible, or use Table Layout → AutoFit → AutoFit to Contents.
  6. Add the header: Insert → Header → Blank → type Price List — 2027 on the left and insert a page number field on the right (Insert → Page Number).
  7. Add the footer: Insert → Footer → type Page X of Y using the page number and total pages fields, centred.
  8. Wrap text around the table: select the table → Table Properties → Text Wrapping → Around, so the paragraph flows beside it.

Exam tips

Check every number twice — "total accuracy" means one wrong digit loses the mark. Gridlines on screen are not the same as borders: gridlines help you see the table while you work, but they do not print unless you add borders. Check Print Preview before you print. The header and footer must be consistent on every page — do not type them on one page only. Merge the cells before you type a title that spans the table, not after.

14

Styles

Styles keep a document consistent. Change the style once, and every heading or paragraph that uses it changes too.

What you must be able to do

  • Create, modify, update and apply styles to ensure consistency of presentation.
  • Control the font in a style: font face, type (serif or sans-serif), point size, colour.
  • Control text alignment: left, right, centre, fully justified.
  • Control text enhancement: bold, underline, italic.
  • Control spacing: paragraph spacing (before and after) and line spacing.
  • Control bullets: shape, alignment, line spacing and indent.

Know and understand: a corporate house style — a fixed set of fonts, colours, sizes and spacing that a company uses on every document so that everything it produces looks the same and is easy to recognise. Its purpose is consistency and a professional image.

Worked example — create a house style for headings

  1. Open the Styles pane: Home → Styles → right-click Heading 1 → Modify.
  2. Set the font: Arial (sans-serif), 16 pt, bold, colour navy #0D2A5C.
  3. Set the spacing: paragraph spacing before 12 pt and after 6 pt, line spacing 1.15.
  4. Click OK. Now select each chapter heading in the document and click Heading 1 in the Styles gallery to apply it.
  5. To update the style later, modify Heading 1 again — every heading using that style updates automatically. You never need to change the headings one by one.
  6. Do the same for the body text: modify the Normal style to Arial 11 pt, line spacing 1.15, and apply it to all body paragraphs.

Exam tips

Never format headings one by one — use styles, or a later change will miss one heading and the document will look inconsistent. A house style is the point of the question: same fonts, same colours, same spacing everywhere. If the task says "update the style", change the style itself — do not re-format the text directly, because direct formatting overrules the style and will not update. Check bullets too: same shape, same indent, same line spacing on every list.

15

Proofing

Proofing is finding and fixing errors before the work is printed — with software tools, and with your own eyes.

What you must be able to do

  • Use automated software tools — spell check and grammar check — and make appropriate changes so the work has as few errors as possible.
  • Use validation routines to minimise data entry errors.
  • Perform visual verification: identify and correct transposed numbers, incorrect spelling, inconsistent character spacing and inconsistent case.
  • Proofread: identify and correct inconsistent line spacing, remove blank pages and blank slides, remove widows and orphans, fix inconsistent or incorrect styles, and make sure tables and lists are not split over columns or pages/slides.

Know and understand: spell check suggestions do not always give the correct answer. Validation checks and their uses:

  • Range check — the value must be inside a set range (a test score must be 0 to 100).
  • Character check — only allowed characters are accepted (a name must not contain digits).
  • Length check — the entry must have a set number of characters (a postcode must be 5 characters).
  • Type check — the entry must be the right data type (a number, not text).
  • Format check — the entry must match a pattern (an email must contain @ and a dot).
  • Presence check — the field must not be left blank.

Verification means checking data that has already been entered — visual checking and double data entry. Validation stops wrong data being entered; verification finds errors that are already there. You need both.

Worked example — proofread a data table before printing

  1. Run the spell check: Review → Spelling & Grammar. Read each suggestion and accept or reject it one by one — do not click "Change All" without reading.
  2. Check the numbers by eye: look for transposed digits, for example 2027 typed as 2072, and for inconsistent case, for example yangon next to Yangon.
  3. Check the validation: a "Score" field must accept only 0–100 (range check); a "Postcode" must be exactly 5 characters (length check); an "Email" must contain @ (format check); a "Name" must not be blank (presence check).
  4. Open Print Preview. Remove any blank page, fix a table that is split across two pages, and fix a heading left alone at the bottom of a page (a widow) or a single line carried onto the next page (an orphan).
  5. Check the spacing: every paragraph the same line spacing, every heading using the same style.

Exam tips

Spell check will not catch "form" typed instead of "from" — both are real words, so only your eyes will find it. A validation check stops a wrong value being entered; verification finds errors that are already entered — know the difference, because the exam asks about both. Always proofread on screen and in Print Preview: blank pages and split tables only show up in the preview.

16

Graphs and charts

A chart turns numbers into a picture. Choose the right chart type, label everything, and format the numbers exactly as the task asks.

What you must be able to do

  • Select data to produce a graph or chart: contiguous data, non-contiguous data, and specified data ranges.
  • Select the graph or chart type.
  • Label the graph or chart: chart title, legend, sector labels, sector values, percentages, category axis title, value axis title, category axis labels, value axis labels, data value labels.
  • Add a second data series and add a second axis.
  • Format numerical values to a specified number of decimal places, and display currency symbols.
  • Adjust the maximum and minimum values of an axis scale and set incremental values.
  • Enhance the appearance: extract a pie chart sector, change the colour scheme or fill patterns.

Worked example — column chart of quarterly sales with a second series

  1. Select the data: click cell A1 and drag to E3. To add a non-contiguous range, hold Ctrl and drag over the second range.
  2. Insert the chart: Insert → Charts → Column Chart → Clustered Column.
  3. Add the title: Chart Design → Add Chart Element → Chart Title → Above Chart → type Sales 2026.
  4. Add axis titles: Add Chart Element → Axis Titles → Primary Horizontal → type Quarter; Primary Vertical → type Sales ($).
  5. Add data labels: Add Chart Element → Data Labels → Outside End, so each value shows above its column.
  6. Add a second series: right-click the 2026 series → Format Data Series → Plot Series On → Secondary Axis. Now the chart has two value axes.
  7. Set the axis scale: right-click the value axis → Format Axis → set Minimum to 0, Maximum to 1000, Major unit to 100.
  8. Format the numbers: select the data labels → set Number format to Currency, $ symbol, 2 decimal places.
  9. For a pie chart: click the largest sector twice to select it alone, then drag it outwards to extract (explode) that sector.

Exam tips

Choose the chart type the data needs: a pie chart shows parts of a whole, a column chart compares values, a line chart shows change over time. A missing chart title or axis title loses marks — label everything. Non-contiguous data needs Ctrl + click: selecting the wrong range is the most common error. Always check the axis scale: a chart that starts at 500 instead of 0 makes small differences look huge. The full step-by-step spreadsheet guide, including charts, is on the Excel Spreadsheets Guide page.

17

Document production

Paper 2 starts here. Document production is building a finished document: page layout, formatted text, find and replace, and bookmarks and hyperlinks.

What you must be able to do

  • Organise page layout: page size, page orientation, page margins, number of columns, column width, spacing between columns, and set or remove breaks — page breaks, section breaks and column breaks.
  • Format text: line spacing (single, 1.5 times, double, multiple) and spacing before and after paragraphs; tabulation — left, right, centred and decimal tabs; indented paragraphs and hanging paragraphs; text enhancement — bold, underline, italic, superscript and subscript, changes in case; bulleted and numbered lists.
  • Find and replace text, including matching case and whole words.
  • Add and delete bookmarks and hyperlinks.

Know and understand: pagination — the purpose of setting page, section and column breaks (to control exactly where a page, a section or a column starts). A gutter margin is the extra space left on the inside edge of a page for binding — it is not the same as a normal margin.

Worked example — format a two-column leaflet

  1. Set the columns: Layout → Columns → Two. Then Layout → Columns → More Columns → set the column width to 7 cm and the spacing between columns to 1 cm.
  2. Set the gutter margin: Layout → Margins → Custom Margins → set the gutter to 1.5 cm for binding.
  3. Set the line spacing: select the heading → Home → Paragraph → Line Spacing → 1.5. Set the spacing after each paragraph to 6 pt.
  4. Set a decimal tab for the price list: click on the ruler to open the Tabs box → set a decimal tab at 12 cm. Now prices line up on the decimal point when you press Tab.
  5. Find and replace: press Ctrl + H → find colour, replace with color → tick Match case → Replace All. Then check the result — "Match case" means only "colour" with a small c is changed.
  6. Add a bookmark: click at the start of the Prices section → Insert → Bookmark → name it Prices → Add.
  7. Add a hyperlink to the bookmark: select the words "See prices" → Insert → Link → Place in This Document → Prices → OK.
  8. Control pagination: put the cursor before the new section → Layout → Breaks → Page Break. Never press Enter many times to push text onto the next page.

Exam tips

A gutter margin is the extra space for binding — do not confuse it with a normal margin. A decimal tab lines numbers up on the decimal point, which is what prices need. "Match case" and "Find whole words only" change what gets replaced — always check the result after replacing. Breaks control where a page, section or column starts; pressing Enter again and again is not a break and will move when the text changes. Superscript is for powers (x²) and subscript is for chemical formulas (H₂O) — the exam tests both.

Databases

Paper 2 continues with databases: build the structure, enter the data, search it with queries, and present it in reports. Work in Microsoft Access.

What you must be able to do

  • Create a database structure: import data from existing files (including .csv and .txt) using specified field names to create tables; set appropriate data types — text, numeric (integer, decimal, currency), date/time, Boolean/logical; set numeric sub-types (percentage, number of decimal places); set the display format of a Boolean/logical field (yes/no, true/false, checkbox); set the display format of date/time data; create and edit primary and foreign keys; create relationships between tables.
  • Create and use a data entry form: specified fields, appropriate font styles and sizes, appropriate spacing between fields, character spacing of individual fields, use of white space, radio buttons, check boxes and drop-down menus.
  • Perform calculations: arithmetic operations or numeric functions in calculated fields and calculated controls — addition, subtraction, multiplication, division, sum, average, maximum, minimum, count.
  • Sort data: a single criterion or multiple criteria, ascending or descending.
  • Search and select data: a single criterion or multiple criteria in a query; operators AND, OR, NOT, LIKE, >, <, =, >=, <=, <>; wildcards.
  • Present data: produce reports showing all the required data and labels in full; use report headers and footers (report header, report footer, page header, page footer); set report titles; use different output layouts (tabular or columnar); align data and labels appropriately — right-align numeric data, decimal alignment; control the display format of numeric data — number of decimal places, currency symbol, percentage.

Know and understand: a flat-file database is a single table with no relationships — simple, but data is repeated and it is hard to keep consistent. A relational database has several linked tables, uses primary and foreign keys, avoids repeating data, and is more secure and efficient. A primary key is a field that is unique for every record and never changes — it identifies the record. A foreign key is a primary key from another table, stored in this table to link the two tables. Good form design means: only the fields the user needs, clear labels, sensible spacing and white space, and the right control for each field (drop-down list for a fixed choice, check box for yes/no, radio buttons for one choice from a few).

Worked example — build a student database and a query

  1. Import the data: External Data → New Data Source → From File → Text File → select Students.csv → tick First Row Contains Field Names → Finish.
  2. Open the table in Design View. Set the data types: StudentID — Short Text; Fee — Currency, 2 decimal places; Paid — Yes/No, display as checkbox; DateJoined — Date/Time, Short Date format.
  3. Set the primary key: right-click StudentID → Primary Key. Save the table.
  4. Create the relationship: Database Tools → Relationships → add the Students and Enrolments tables → drag StudentID from Students onto StudentID in Enrolments → tick Enforce Referential Integrity → Create.
  5. Build a query: Create → Query Design → add the Students table → drag the fields Surname, Score and Town into the grid.
  6. Add criteria: type >=50 under Score (only scores of 50 or more); type Like "Sm*" under Surname (only surnames starting with "Sm"). Criteria on the same row means AND — both must be true.
  7. Add a calculated field: in an empty Field cell type Total: [Quantity]*[UnitPrice]. Access multiplies the two fields for every record. A calculated control on a form or report works the same way.
  8. Sort the results: under Surname set Sort to Ascending; under Score set Sort to Descending. Run the query (Run, the red exclamation mark).
  9. Make the report: select the query → Create → Report. Set the report title at the top, add a report header with the school name, and a page footer with page numbers. Right-align all numeric data and check that every label and every value shows in full — nothing cut off.
  10. Take the evidence screenshot of the report in Print Preview and place it in your Evidence Document.

Query operators you must know: AND (both true), OR (at least one true), NOT (not true), LIKE (matches a pattern), >, <, =, >=, <=, <> (not equal). In ("London", "Birmingham") matches a value in a list. Wildcards: * matches any number of characters (Sm* finds Smith, Small, Smythe), ? matches exactly one character (Sm?th finds Smith and Smyth).

Exam tips

Never use a name as a primary key — names can repeat. The primary key and the foreign key must be the same data type, or the relationship will fail. In a query, criteria on the same row means AND and criteria on different rows means OR — this is the most tested rule in the whole section. * matches any characters and ? matches one character. A report must show all labels and data in full: text cut off at the edge of a column loses marks. Always take the evidence screenshot of the report and of the relationship window.

19

Presentations

Paper 2 ends with presentations: build the slides from a text file, make them consistent with a master slide, add links and buttons, and show or print them in the right way.

What you must be able to do

  • Create a presentation using a text file.
  • Use a master slide: insert and edit objects consistently — images, text, shapes, logos, slide headers and footers, placeholder position, automated slide numbering. Format master slide objects — headings, subheadings, bullets, background colour.
  • Edit a presentation: apply a slide layout; insert a new slide; move or delete a slide; insert and edit objects — text (headings, subheadings, bulleted lists), images (still images, video clips, animated images), charts, tables, audio clips (sound), symbols, lines, arrows, call-out boxes and shapes.
  • Add presenter notes.
  • Insert and edit a hyperlink — link text or an object to a slide inside the presentation, an external file, or an email address.
  • Insert an action button and change its settings to navigate to a specified slide or file.
  • Add alternative text (alt text) or a screentip to an object.
  • Apply consistent transitions between slides and consistent animation effects on text, images and other objects.
  • Hide slides inside a presentation.
  • Output the presentation: display it as a looped on-screen carousel or presenter controlled; print it as full page slides, presenter notes, or handouts.

Worked example — build a 6-slide talk from a text file

  1. Create the presentation from the text file: New → Open the outline text file, or Home → New Slide → Slides from Outline → select Talk.txt. Each line becomes a slide title or a bullet point.
  2. Set up the master slide: View → Slide Master. Insert the school logo, the footer text and the slide number field once — they now appear on every slide. Set the heading font, the subheading font, the bullet style and the background colour here.
  3. Apply layouts: select each slide → Home → Layout → choose Title and Content for text slides and Title Only for the picture slide.
  4. Add objects: Insert → Pictures for a still image; Insert → Chart for a chart; Insert → Table for a table; Insert → Audio for a sound clip. Add a call-out box with Insert → Shapes → Callout.
  5. Add presenter notes: click in the Notes pane under a slide and type what the presenter should say.
  6. Add a hyperlink: select the logo → Insert → Link → type the school website address. Or link text to another slide: Place in This Document → Slide 6.
  7. Add an action button: Insert → Shapes → Action Buttons → Home → draw the button on the last slide → in the Action Settings box choose Hyperlink to: First Slide → OK.
  8. Add alt text: right-click an image → Edit Alt Text → type a short description, for example School logo.
  9. Make transitions and animation consistent: select all slides → Transitions → Fade → Apply to All. Select a bullet list → Animations → Appear. Use the same transition and the same animation everywhere.
  10. Hide the backup slide: right-click it in the slide pane → Hide Slide. It stays in the file but does not show in the slide show.
  11. Set up the show: Slide Show → Set Up Show → Loop continuously until 'Esc' for a carousel display, or leave it presenter controlled for a talk.

Exam tips

Put repeated items — logo, footer, slide numbers — on the master slide. Never place them on every slide by hand: one slide will always be missed. Transitions and animation must be consistent — mixing five different effects looks unprofessional and loses marks. A hidden slide does not show in the slide show but it still prints, so check the printout. Always check that presenter notes print correctly: choose Notes Pages in the print settings, not full page slides, when the task asks for notes.

20

Spreadsheets

Paper 3 starts here. Spreadsheets are the biggest practical topic: build a data model with formulae and functions, sort and search the data, then format it and print it.

What you must be able to do

  • Create and edit a spreadsheet model: insert or delete cells, rows and columns; merge cells; create formulae using cell references; replicate formulae using absolute and relative cell references where appropriate; use arithmetic operators — add, subtract, multiply, divide, indices (powers); use named cells and named ranges; use functions — SUM, AVERAGE, MAX, MIN, INT, ROUND, COUNT, LOOKUP, VLOOKUP, HLOOKUP, XLOOKUP, IF; use external data sources inside functions; use nested functions.
  • Manipulate data: sort with a single criterion or multiple criteria, ascending or descending; search and select subsets of data with a single criterion or multiple criteria, using operators AND, OR, NOT, >, <, =, >=, <=, <>, and wildcards.
  • Present data: display formulae or values; adjust row height, column width and cell sizes so all data, labels and formulae are fully visible; wrap text inside cells; hide and display rows and columns; format a spreadsheet — text colour, cell colour, bold, underline, italic, shading; format numbers — decimal places, currency symbols, percentages; use conditional formatting to change how a cell looks depending on its contents; set page layout — portrait or landscape orientation, print on a specified number of pages, print area, show or hide gridlines, show or hide row and column headings.

Know and understand: a formula is a calculation you write yourself with cell references and operators, for example =B2+C2. A function is a ready-made calculation with a name, for example =SUM(B2:B5). The order of operations is: brackets first, then indices (powers), then multiplication and division, then addition and subtraction — use brackets to make sure a formula works as you mean it. A relative reference (B2) moves when you copy a formula; an absolute reference ($B$2) stays fixed.

Worked example — build a grade calculator

Student names are in A2:A5, scores in B2:B5. Cell B1 holds the pass mark, 50. The grade table is on a sheet called Grades, in A2:B6.

  1. Name the pass mark cell: click cell B1, click in the Name Box (left of the formula bar), type PassMark and press Enter. Now the formula can use the name PassMark instead of $B$1.
  2. Total and average: in B6 type =SUM(B2:B5); in B7 type =AVERAGE(B2:B5); in B8 type =ROUND(AVERAGE(B2:B5),2) to show the average to 2 decimal places.
  3. Highest and lowest: in B9 type =MAX(B2:B5); in B10 type =MIN(B2:B5); in B11 type =COUNT(B2:B5) to count how many scores there are.
  4. Pass or fail: in C2 type =IF(B2>=PassMark,"Pass","Fail"). Copy the formula down to C5 — the relative reference B2 changes to B3, B4, B5, but the named cell PassMark stays fixed.
  5. Look up the grade: in D2 type =VLOOKUP(A2,Grades!$A$2:$B$6,2,FALSE). The $ signs make the table range absolute, so it does not move when you copy the formula down. FALSE means exact match — the name must be found exactly. Copy D2 down to D5.
  6. Nested function: in E2 type =IF(AVERAGE(B2:B5)>=80,"Distinction",IF(AVERAGE(B2:B5)>=50,"Pass","Fail")). Count the brackets: every opening bracket needs a closing one.
  7. Order of operations: =2+3*4 gives 14 (multiplication first). =(2+3)*4 gives 20 (brackets first). Use brackets whenever you are not sure.
  8. Sort the data: select the table → Data → Sort → sort by Score, Largest to Smallest, then add a level → sort by Name, A to Z.
  9. Conditional formatting: select B2:B5 → Home → Conditional Formatting → Highlight Cells Rules → Greater Than → type 80 → choose green fill. Now every score above 80 turns green automatically.
  10. Page layout: Page Layout → Orientation → Landscape; set Fit to 1 page wide; set the Print Area to A1:E11; untick Print Gridlines if the task says so. Check Print Preview — every value must be fully visible, with no ### showing in a column that is too narrow.
  11. Formula view: Formulas → Show Formulas displays the formulae instead of the values. Take a screenshot of the formula view for your Evidence Document, then switch it off again.

Exam tips

A relative reference moves when you copy a formula; an absolute reference ($A$1) does not — always use $ on a lookup table range, or the range will slide down and the lookup will break. VLOOKUP needs FALSE for an exact match, and the lookup value must be in the first column of the table. Nested IFs need the same number of closing brackets as opening ones — count them. A column that is too narrow shows ### instead of the number: widen the column before printing. Always check the printed page shows all data in full.

Website authoring

Paper 3 ends with website authoring: build a web page with HTML for the content and CSS for the presentation. No scripting language is required.

The three web development layers

  • Content layer (HTML) — enter the content and create the structure of a web page.
  • Presentation layer (CSS) — display and format the elements in a web page.
  • Behaviour layer (a scripting language) — control elements in a web page. This layer is not needed for this exam.

What you must be able to do — HTML (content layer)

  • Place elements in the head section: a page title to display in the browser; attach external stylesheets with the correct hierarchy, using a relative file path; metatags with the right attributes — charset, name attributes (description, keywords, author, viewport) and content attributes; default target windows.
  • Place content in the body section.
  • Insert a table: table header (<th>), table rows (<tr>), table data (<td>). Adjust cells to span more than one row or column (rowspan, colspan), set table and cell sizes in pixels or % values, and apply styles to tables.
  • Insert objects: text, images, sound clips, video (display controls, remove controls, autoplay); adjust image or video size and aspect ratio; apply alternative text.
  • Use the <div> tag to apply styles and classes.
  • Apply tags to text to display pre-defined styles: <h1>, <h2>, <h3>, <p>, <li>. Apply classes to elements. Apply styles to lists — ordered list (<ol>) and unordered list (<ul>).
  • Create a bookmark inside a web page using an id attribute.
  • Create hyperlinks from text and images to: a bookmark on the same page; another locally stored web page; a website using its URL; an email address (send mail); and open in a specified location — the same window, a new window, or a window with a specified name.

Know and understand: the purpose of the head section (metadata — information about the page, not shown on the page) and the body section (the visible content). Tables are used to structure elements in a web page. Metatags define the charset, keywords for search engines, the author, a description of the page, and the viewport (so the page displays correctly on all devices). A hyperlink takes the user to another place. A bookmark is a named place in a page, made with an id attribute, that a link can jump to. An anchor is the link itself (<a>). A relative file path gives the location of a file compared with the current page (for example style.css or images/logo.png); an absolute file path gives the full location on one computer (for example C:\Users\Name\site\style.css) — absolute paths must not be used for hyperlinks to locally saved web pages or objects, because they break on any other computer.

What you must be able to do — CSS (presentation layer)

  • Create the presentation layer of a web page. Create generic external styles and inline style attributes: background properties (colour, images), font properties, and table, table row, table header and table data properties — size, background colour, horizontal and vertical alignment, spacing, padding, borders (including collapsed, colour, thickness, visible or invisible).
  • Create classes with the same properties (background, font, table properties).
  • Create external styles to be tagged in a web page: h1, h2, h3, p, li.
  • Specify font properties: font family, size, colour, alignment, bold, italic.
  • Attach comments to an external stylesheet, and save styles in cascading stylesheet (.css) format.

Know and understand: in a cascading stylesheet, an inline style attribute overrules an attached (external) stylesheet, and when several stylesheets are attached, the last one attached wins for any property they both set. A style applies to an HTML tag (every h1 looks the same); a class can be applied to any element that carries that class name, so the same class can style different tags. Relative file paths must be used for attached stylesheets.

Exam tips

Always use relative file paths for local pages, images and stylesheets — an absolute path such as C:\Users\... works only on your computer and breaks on the examiner's computer. An inline style beats an external stylesheet, and the last attached stylesheet wins — check the hierarchy if a style does not apply. A class (.main-title) can be reused on many elements; an id (#courses) is unique and is used for bookmarks. Every image needs alt text. Check every link target: _blank opens a new window and _self opens in the same window.
