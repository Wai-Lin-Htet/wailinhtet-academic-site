1. What is a Database?

  • Stores data in a structured way using tables, fields, and records.
  • Helps organise, find, update, and manage data efficiently without redundancy.
  • Microsoft Access is a Relational Database Management System (RDBMS).

2. Flat-File vs Relational

Flat-File Database

Single table only. No relationships. Less secure and flexible (e.g., CSV file).

Relational Database

Multiple linked tables. Uses primary & foreign keys. More secure & efficient (e.g., MS Access).

4. Primary Key

  • Must be unique and stable for every single record.
  • Prefer the provided ID field given in the task specifications.
  • If no ID field exists, create a surrogate key only if allowed.
  • Avoid using names, towns, or categories as primary keys due to possible duplication.

5. Relationships

  • Connect Primary Key in parent table → Foreign Key in child table.
  • Linked fields must be of the exact same data type and meaning.
  • Enable Enforce Referential Integrity when prompted.
  • Save and capture clear evidence screenshots of your relationship window.
Practical Data Entry Guide

How to Insert Data into Microsoft Access

Follow this step-by-step procedure to create tables, define attributes, and input data seamlessly into your Access database.

1

Create Database & Table

Open MS Access, click Blank Database. Go to the Create tab, click Table Design to build your structure from scratch.

2

Define Fields & Data Types

Enter your field names in column one, choose appropriate data types from the dropdown, and set your Primary Key using the key icon on the top ribbon. Save the table.

3

Switch to Datasheet & Insert

Switch from Design View to Datasheet View by clicking the View icon. Type or paste your records row by row carefully ensuring proper formatting.

6. Creating New Field

Define field name and data type. Set brackets and order of operations for calculated results like totals.

Total: [Quantity] * [UnitPrice]

7. Queries

Use correct criteria rows. Same row = AND, separate rows = OR. Use wildcards like * correctly.

[Town] In ("London", "Birmingham")

8. Sort & Filter

Check which field is being sorted. Use secondary sorts if specified. Ensure records match exact subsets.

ORDER BY Name ASC, Date DESC

9. Reports & Forms

Design clean reports with grouping and sorting. Create intuitive forms with validation rules and input masks.
