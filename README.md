## 📚 Curriculum Covered

* **Cambridge Assessment International Education:**
  * IGCSE Computer Science (0478)
  * IGCSE Information & Communication Technology (0417)
  * Cambridge International AS & A Level Computer Science (9618)
* **Ontario Secondary School Diploma (OSSD):**
  * Grade 11 & Grade 12 Computer Science (ICS3U / ICS4U)
* **Edexcel International GCSE:**
  * ICT (4IT1)

---

## 🛠 Features

- **PWA Ready:** Installable directly on iOS, Android, macOS, and Windows with offline-caching support via Service Worker.
- **Interactive Revision Portals:** Includes Paper 1 & Paper 2 revision tools, logic gate simulators, pseudocode references, and past paper repositories.
- **Responsive Bento UI:** Optimized for all screen sizes (mobile, tablet, desktop) with high-legibility typography and dark/light system integration.
- **Instant Deployment:** Connected with Netlify CI/CD pipeline for automatic multi-device synchronization upon GitHub push.
