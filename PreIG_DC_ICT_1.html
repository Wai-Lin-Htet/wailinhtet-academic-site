1.1 What Is Technology?

Technology refers to the tools, systems, devices, and processes people use to solve problems and accomplish tasks. Modern information technology focuses heavily on computers, mobile devices, networks, software, the Internet, and digital information. Computing technology affects nearly every part of daily life—from communication and education to banking, transportation, healthcare, entertainment, and manufacturing. The important idea is that technology is not limited to traditional computers. Smartphones, smart watches, game consoles, ATMs, cars, medical equipment, and household appliances can all contain computing technology.

1.2 Types of Computers

Four common categories of computers are desktops, laptops, tablets, and servers. A desktop computer normally stays in one location and provides strong performance and upgradeability. A laptop is portable and integrates a screen, keyboard, pointing device, processor, storage, and battery. A tablet is smaller and lighter than most laptops and uses a touchscreen interface. A server provides resources or services (websites, files, databases) to other computers and devices over a network.

1.3 Smartphones and Digital Devices

A smartphone combines communication, computing, Internet access, photography, navigation, and entertainment. Digital cameras capture photographs and video digitally. Portable and digital media players store and play multimedia content. E-book readers are specialized for digital books. Wearable devices include smartwatches and fitness trackers. Dedicated game consoles, handheld systems, and gaming computers facilitate interactive entertainment.

1.4 Data and Information

Data consists of raw facts, figures, symbols, sounds, images, or elements that a computer processes. Information is data that has been organized, processed, or interpreted so that it becomes useful (e.g., individual exam scores represent data; the calculated class average represents information). The basic operational pipeline is: Data → Processing → Information.

1.5 Input Options

Input is any data or instructions entered into a computer. Common input methods include keyboards, mice, touchscreens, microphones, digital cameras, scanners, barcode readers, fingerprint scanners, styluses, motion sensors, and voice commands.

1.6 Internet and the Web

The Internet is a worldwide network of interconnected computer networks. The World Wide Web (Web) is an information service operating over the Internet infrastructure consisting of webpages, websites, web servers, and web applications. Browsers retrieve and render web content hosted on web servers.

1.7 Browsers, Search Engines, and Social Networks

A browser accesses and displays webpages. A search engine indexes and locates information across the web using keyword queries. An online social network allows users to create profiles, publish media, communicate, and interact with individuals or organizations.

1.8 Digital Security, Privacy, Health, and Environment

Malware (viruses, worms, Trojans, ransomware) damages systems and exfiltrates information. Privacy concerns arise from large-scale tracking and automated profiling. Physical hazards include poor posture, repetitive stress injuries, and eye strain. Electronic waste management and energy-conscious usage define green computing practices.

1.9 Operating Systems and Applications

An operating system (Windows, macOS, Linux, Android, iOS) manages core system hardware, executes resource scheduling, and hosts user applications. Applications (word processors, browsers, databases) perform explicit user tasks under operating system management.

1.10 Networks and Technology in Society

Networks link computing devices using wired or wireless transmission media to share files, hardware peripherals, and database resources across education, government, finance, retail, entertainment, and manufacturing sectors.

2.1 Evolution of the Internet

The Internet expanded from early military and academic research initiatives into a global public communications system. Transitioning through commercial expansion, the emergence of the World Wide Web, broadband upgrades, mobile networks, and cloud architecture, it now forms the backbone of global transactions and communications.

2.2 Broadband Connections

High-speed broadband delivery includes cable, fiber-optic (offering very high bandwidth via light pulses), DSL, fixed wireless, cellular networks (4G/5G), and satellite arrays suitable for areas lacking wired cable backbones.

2.3 IP Addresses and Domain Names

Every node communicating over an IP network requires an IP address for routing. The Domain Name System (DNS) translates human-readable domain names into numerical IP addresses to locate remote web servers.

2.4 Web Addresses (URLs)

A Uniform Resource Locator (URL) details the protocol (e.g., HTTPS for encrypted communications), domain name, resource path, file name, and optional parameters required to retrieve a target online asset.

2.5 Search Techniques and Information Evaluation

Search optimization involves using specific terms, eliminating unnecessary filler words, and utilizing quotation marks for exact phrasing. Information retrieved must be systematically evaluated for authority, currency, bias, and accuracy.

2.6 Social Networking Dynamics

Social networks facilitate professional networking and communal sharing, but present security risks including identity theft, targeted social engineering, surveillance capitalism, cyberbullying, and unintentional exposure of sensitive data.

2.7 Web Publishing Process

Standard website deployment follows a structured sequence: system planning, layout design, asset development, domain acquisition, server hosting configuration, asset upload via secure protocols, functional link/form testing, and ongoing site maintenance.

2.8 Digital Media and Online Communication

The Web delivers rich multimedia including vector/raster graphics, animation, streaming audio, and immersive virtual reality environments. Core protocols enable email, instant messaging, forums, Voice over IP (VoIP), and File Transfer Protocol (FTP).

2.9 Netiquette

Online etiquette requires courteous interaction, avoiding uppercase typography to signal shouting, maintaining message confidentiality, fact-checking links before forwarding, and crediting copyright owners.

3.1 Selecting Computing Form Factors

Hardware selection aligns with portability, raw compute requirements, and modularity. Laptops and tablets emphasize portability and battery efficiency, while desktop workstations accommodate demanding workloads and component replacements. All-in-ones consolidate the processor and motherboard directly behind the display unit.

3.2 Enterprise and Dedicated Hardware

Servers handle central network requests. Point of Sale (POS) terminals process transactions, Automated Teller Machines (ATMs) connect to banking mainframes, and interactive kiosks facilitate independent airline check-ins and ticketing. Supercomputers and mainframes perform large-scale scientific simulations and secure enterprise transaction pipelines.

3.3 Cloud Computing Integration

Cloud architectures deliver computing power, remote database storage, and software instances over the Internet, allowing organizations to avoid purchasing and maintaining on-premises server infrastructure.

3.4 Embedded Systems

Embedded computers run specialized microcode designed to regulate dedicated appliances, including industrial assembly arms, automobile engine management systems, smart thermostats, and medical monitors.

3.5 Ports, Connectors, and Wireless Links

A port is a physical interface point; a connector is the cable end fitting into that interface. Short-range data sharing relies on Bluetooth or Near Field Communication (NFC, standard for tap-to-pay), while local network links operate over Wi-Fi channels.

3.6 Hardware Preservation and Ergonomics

Hardware protection requires physical cable locks, surge arrestors, uninterruptible power supplies (UPS), and dust filtration. Ergonomic workspace setups incorporate adjustable monitors at eye level, lumbar support, and wrist alignments to prevent repetitive strain injury (RSI).

4.1 Software Classifications

System software administers base-level computer routines; application software satisfies discrete user tasks (e.g., calculation, typesetting); and utility software diagnoses, optimizes, and secures persistent storage.

4.2 Hardware Abstraction by Operating Systems

Applications make standard system calls to the operating system rather than controlling physical buses directly. The OS translates these instructions into specific hardware operations for target display controllers, memory banks, and network interfaces.

4.3 Software Distribution Models

Software acquisition models include commercial off-the-shelf retail software, custom bespoke programs, browser-executed web applications, open-source software (where source code is accessible for modification), freeware, and shareware distributed on trial terms.

4.4 Productivity and Creative Suites

Productivity software includes word processors, spreadsheet packages that calculate numerical models, relational database systems, and slide presentations. Creative tools include Computer-Aided Design (CAD) for technical blueprints, desktop publishing platforms, raster/vector graphics packages, and digital audio workstations.

4.5 Utility and Maintenance Software

System tools maintain system integrity and performance, including disk defragmenters, file compression tools, automated backup software, memory monitors, uninstallation engines, personal firewalls, and malware scanners.

Digital Security, Ethics, and Privacy: Threats, Issues, and Defenses

  • Discuss information privacy issues (cookies, phishing, spyware, workplace monitoring)

5.1 Cybercrime Threats and Network Exploits

Malware includes viruses (which inject instructions into executable files), self-replicating worms, disguised Trojans, spyware, and ransomware that encrypts user data for extortion. Botnets harness hijacked computers to launch distributed denial-of-service (DDoS) attacks that take down network services.

5.2 Access Control and Identity Safeguards

Access control verifies authorization through multi-factor authentication (MFA): knowledge factors (strong passphrases), possession factors (security key tokens, authenticator apps), and biometric factors (fingerprints, facial geometry analysis).

5.3 Cryptography and Authentication

Encryption algorithms translate plaintext into unreadable ciphertext, which can only be decoded with the correct key. Digital certificates issued by trusted Certificate Authorities (CAs) authenticate web server domains under TLS/HTTPS. Digital signatures verify message integrity and author authenticity.

5.4 Backup Strategies

System backups protect against hardware failure, file corruption, and ransomware attacks. Backups should be taken frequently, tested for restoration viability, and maintained across external local media and air-gapped cloud repositories.

5.5 Digital Ethics, Intellectual Property, and Privacy

Ethical computing encompasses respect for intellectual property rights, adhering to software copyright licenses, preventing academic plagiarism, managing tracking cookies, identifying deceptive phishing vectors, and complying with data privacy laws.

6.1 Processor Architecture and the Machine Cycle

The Central Processing Unit (CPU) interprets and executes computer instructions. Multi-core chips package multiple physical execution cores onto one integrated circuit. The processor executes instructions through a repeating 4-step cycle: Fetch (retrieve instruction from memory), Decode (translate instruction into signals), Execute (perform arithmetic or logic operation), and Store (write result back to memory or register).

6.2 System Memory: Volatile vs. Non-Volatile

Random Access Memory (RAM) provides temporary, volatile working memory for running applications. Read-Only Memory (ROM) houses permanent, non-volatile firmware instructions. High-speed processor cache stores frequently used data to speed up instructions, while solid-state flash memory provides persistent storage without moving parts.

6.3 Binary Representation

All software instructions, character strings, audio signals, and visual data reduce to binary bits (0 or 1). Eight bits form a byte, which can represent 256 distinct values under standardized encoding formats such as ASCII or Unicode.

6.4 System Expansion, Cooling, and Buses

High-performance CPUs require cooling systems such as copper heat sinks, high-CFM fans, and closed-loop liquid thermal solutions. Internal buses provide high-speed communication channels between system memory, processing pipelines, and expansion cards.

7.1 Pointing Devices and Input Hardware

Input systems translate physical human interaction into binary data. Technologies include ergonomic mechanical keyboards, optical mice, trackballs, touchpads, touchscreens, styluses, and digitizer drawing tablets.

7.2 Scanning and Recognition Technologies

Data entry automation uses specialized hardware: flatbed optical scanners, Optical Character Recognition (OCR), barcode and QR readers, Radio Frequency Identification (RFID) antennas, magnetic stripe readers, and Magnetic Ink Character Recognition (MICR) scanners used for check processing.

7.3 Display Characteristics and Output Formats

Displays use LCD, LED, and OLED panels. Screen quality depends on pixel density (resolution), color accuracy, contrast ratio, viewing angle, and refresh rate (Hz). Digital projectors project images onto large surfaces for audiences.

7.4 Printing Technologies

Common printer categories include inkjet printers that deposit liquid ink droplets for color imagery, laser printers that use toner cartridges and heated fuser drums for fast document output, thermal printers for receipt generation, and 3D printers that construct solid physical models layer by layer.

7.5 Assistive Input and Output Solutions

Assistive technology makes systems accessible to users with disabilities through screen readers, Braille displays, switch access systems, speech-to-text engines, eye-tracking systems, and screen magnifiers.

Digital Storage: Preserving Content Locally and on the Cloud

Objectives Overview

  • Differentiate between storage and memory
  • Describe internal hard disk drives (HDDs) and solid-state drive (SSD) benefits
  • Identify uses of external drives, RAID configurations, and flash storage
  • Discuss the benefits, uses, and security of cloud storage
  • Describe characteristics and longevity of optical media
  • Explain enterprise storage architectures (RAID, NAS, SAN, tape libraries)
  • Identify uses of smart cards, magnetic stripes, RFID, and NFC tags

8.1 Storage Media vs. System Memory

Storage holds data persistently without power, whereas system memory (RAM) is volatile and clears its data when powered down. Storage devices provide significantly larger storage capacity at a lower cost per gigabyte than RAM.

8.2 Magnetic HDDs vs. Solid-State Drives

Hard disk drives read and write data using magnetic read/write heads positioned over spinning platters, making them susceptible to mechanical shock. Solid-state drives use flash memory with no moving parts, delivering faster read/write speeds, lower power consumption, and better shock resistance.

8.3 Redundancy and Enterprise Storage Systems

Enterprise systems use redundant disk arrays (RAID 0, 1, 5, 10) to improve read/write throughput and prevent data loss from drive failures. High-capacity business storage relies on Network Attached Storage (NAS) appliances, dedicated Storage Area Networks (SAN), and high-density magnetic tape cartridges for archival storage.

8.4 Cloud and Optical Formats

Cloud storage enables synchronized, off-site file access across mobile and desktop devices. Optical discs (CD, DVD, Blu-ray) use laser reflections to read microscopic pits on a disc surface, serving as low-cost physical media for software distribution and archival storage.

Operating Systems: Managing, Coordinating, and Monitoring Resources

Objectives Overview

  • Define an operating system and describe its core responsibilities
  • Describe the system startup sequence (booting) and shutdown modes
  • Explain UI management, process scheduling, memory allocation, and multitasking
  • Describe device driver configuration and network performance monitoring
  • Identify built-in file management and automated update utilities
  • Explain user permissions, network administration, and access security
  • Compare desktop, server, and mobile operating system environments

9.1 Operating System Roles and Boot Sequences

An operating system manages computer hardware and provides common services for user software. During the boot process, firmware (BIOS/UEFI) runs initial hardware diagnostic checks, initializes components, and loads the operating system kernel into system RAM.

9.2 Memory Management and Process Scheduling

The operating system manages multiple programs simultaneously through process scheduling algorithms that assign CPU time slices to active threads. Virtual memory management uses persistent storage as an overflow buffer (paging file/swap space) when RAM capacity is exceeded.

9.3 Device Communication via Drivers

Operating systems rely on device drivers to communicate with hardware peripherals. Device drivers translate generic read/write calls from the operating system into the specific signals required by a printer, display adapter, or network card.

9.4 Operating System Categories

Desktop operating systems (Windows, macOS) balance multi-window user interfaces and gaming/productivity applications. Server operating systems (Linux, Windows Server) prioritize network throughput, system uptime, and multi-user security permissions. Mobile operating systems (Android, iOS) are optimized for battery conservation, touch interaction, and continuous cellular/Wi-Fi switching.

Communicating Digital Content: Wired and Wireless Networks and Devices

  • Differentiate client/server and peer-to-peer network topologies
  • Explain network communication standards (Ethernet, TCP/IP, Wi-Fi, LTE, Bluetooth, NFC)

  • Discuss secure residential network setup and administration

10.1 Network Topologies and Geographical Scope

Computer networks connect nodes to exchange data and share peripheral resources. Common network scopes include Personal Area Networks (PANs) connecting personal devices, Local Area Networks (LANs) across single buildings, Metropolitan Area Networks (MANs) across city districts, and Wide Area Networks (WANs) spanning global distances. The Internet is the largest example of a WAN.

10.2 Architectural Models: Client/Server vs. P2P

In client/server architectures, centralized host systems store database records, manage authentication, and serve files to end-user client devices. In peer-to-peer (P2P) topologies, every computer on the network shares files and peripheral access directly with other nodes without requiring a central server.

10.3 Core Network Hardware

Modems convert analog signals from an Internet service provider into digital signals that local computers can process. Switches direct data packets to specific devices within a single local area network, while routers inspect packet header addresses to route traffic between different networks.

10.4 Physical and Wireless Transmission Media

Physical network cables include unshielded twisted-pair copper wire (e.g., Cat6 Ethernet) and fiber-optic cables that transmit light pulses to provide immune-to-interference data links over long distances. Wireless transmission channels use radio frequency spectra, including Wi-Fi, cellular broadband (LTE/5G), microwave transmissions, and satellite arrays.
